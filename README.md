# Iris Dataset Analysis

## Objective
Understand how to read, summarize, and visualize a dataset using Python.

## Dataset
Iris Dataset (CSV format from seaborn)

## What's Included
- `iris_analysis.py` — Complete Python script with fully commented code
- Scatter plots, histograms, and box plots for data visualization
- Data loading, inspection, and summarization using pandas

## How to Run
1. Install dependencies: `pip install pandas matplotlib seaborn`
2. Run the script: `python iris_analysis.py`

## Skills Learned
- Data loading with pandas
- Data visualization with matplotlib and seaborn
- Statistical analysis and outlier detection
